# Prerendered theme backdrops

Drop a seamless video loop here named after the theme and it plays
automatically behind profiles using that theme (with a readability
scrim). No code changes needed.

- Filenames: ps3.webm, ps4.webm, xbox-og.webm, xbox-360.webm,
  wii.webm, limewire.webm, crt-blue.webm (.mp4 also works as a
  fallback source)
- Specs: 8-20 second SEAMLESS loop, 1080p or 720p, muted (no audio
  track needed), target 2-6MB (WebM/VP9 at low bitrate is fine -
  abstract motion compresses beautifully)
- IMPORTANT: only original/licensed renders. Actual Sony/Microsoft
  dashboard footage is their copyright - "inspired by" recreations
  only (colors + motion language, not their assets).
- When no file exists for a theme, the built-in CSS animation runs
  instead. Delete a file to fall back.
